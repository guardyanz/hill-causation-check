# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a vulnerability

This repository contains a Markdown skill, a Markdown template, and a small Python script that reads local Markdown files. It makes no network calls, stores no credentials, and runs no services.

If you find a security issue (for example, a path-traversal or code-execution problem in `scripts/check_scorecard.py`), please report it privately rather than opening a public issue:

1. Open a GitHub Security Advisory on this repository, or email the maintainer via the address listed on the repository profile.
2. Include a minimal reproduction and the version you tested.
3. Allow a reasonable time for a fix before public disclosure.

Do not include personal health information in any report.

## Scope note

This skill assesses the strength of published evidence for general claims. It is not a medical device and does not give personal medical advice. Misuse of a verdict as medical advice is out of scope for this policy — see the medical disclaimer in `README.md` and `SKILL.md`.
